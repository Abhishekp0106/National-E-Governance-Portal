Portal Architecture & Workflow Traceability

System operational specifications and architectural workflow standards:

  • Module 1 Workflow: Draft ➔ Submitted ➔ Under Verification (Govt Officer) ➔ Pending Approval ➔ Approved / Rejected (Dept Head) ➔ Closed
  • Module 2 Workflow: Filed ➔ In Progress (Officer Investigation) ➔ Resolved / Escalated ➔ Closed + Citizen Feedback Rating
  • Relational DB Persistence: Node SQLite relational schema backing users, departments, services, applications, documents, and audit logs.
  • Testing Verification: Black-Box Boundary Value Analysis (BVA), Equivalence Partitioning (EP), and Role-Based Authorization validation.
